# Project_ReactionTest

The Reaction Game is a project developed during the first year of the Electrical Engineering program. 

The purpose of the project was to combine electronics, programming, and measurement technology into an interactive system that clearly demonstrates how human reaction time can be analyzed.

The game is designed to test the user's reaction speed using three different types of stimuli: sight, hearing, and touch. The system measures how quickly the user responds to each signal and collects the data to provide feedback on their reaction time. The results are then presented in a histogram, allowing the user to easily view and compare their performances.
