# Project_ReactionTest
Reaction Game är ett projekt som vi utvecklade under år 1 på elektro programmet. 

Projektets syfte var att kombinera elektronik, programmering och mätteknik i ett interaktivt system som på ett tydligt sätt visar hur människans reaktionsförmåga kan analyseras.

Spelet är gjort för att testa användarens reaktionsförmåga genom tre olika typer av signaler: syn, hörsel och känsel. 
Systemet mäter hur snabbt användaren reagerar på varje signal och samlar in resultaten för att ge feedback på reaktionstiden. Resultatet presenteras sedan i form av ett histogram, så att användaren enkelt kan se och jämföra sina prestationer.
